# Pot of Study

A responsive study planning workspace for students.

## Current milestone

This repository contains the first UI-only foundation: dashboard, subjects, tasks, progress, notes, timetable, login, register, responsive navigation, and dark mode. Firebase Authentication and Firestore are intentionally not wired yet; they are the next major feature step.

## Development

This project uses pnpm workspaces. Run pnpm install, then start the Pot of Study artifact with the workspace workflow.
